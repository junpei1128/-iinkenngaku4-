# Gmail設定の再構築手順

## 過去の設定を思い出す方法

### 1. Googleアカウントのアプリパスワード一覧を確認

1. 以下のURLにアクセス：
   ```
   https://myaccount.google.com/apppasswords
   ```

2. 以前生成したアプリパスワードの一覧が表示されます
   - 名前が「医院見学レポートシステム」「iinkenngaku4」などのものが該当する可能性があります
   - **注意**: アプリパスワードは一度表示された後は再表示されません
   - 既存のアプリパスワードが表示されない場合は、新しいものを生成する必要があります

### 2. 以前使用していたGmailアカウントを確認

- 業務用のGmailアドレス（例: `@consuldent.jp` など）
- 個人用のGmailアドレス
- システム専用のGmailアドレス

### 3. 現在の設定を確認

以下のコマンドで現在の設定を確認できます：

```bash
cd server
npm run check-env
```

## 新しい設定を行う場合

### ステップ1: Gmailアプリパスワードの生成

1. Googleアカウントにログイン: https://myaccount.google.com/
2. **セキュリティ** をクリック
3. **2段階認証プロセス** が有効になっていることを確認（無効の場合は有効化）
4. **アプリパスワード** をクリック（2段階認証を有効にした後に表示されます）
5. **アプリを選択** → **その他（カスタム名）** を選択
6. 名前を入力（例: `医院見学レポートシステム`）
7. **生成** をクリック
8. **重要**: 表示された16文字のパスワードをコピーしてください（この画面でしか表示されません）
   - 形式: `xxxx xxxx xxxx xxxx`（スペースを含む16文字）
   - 実際に使用する際は、スペースを削除して16文字の文字列として使用します

### ステップ2: .envファイルの編集

1. `server/.env` ファイルを開く
2. 以下の2行を実際の値に置き換える：

```env
GMAIL_USER=your-actual-email@gmail.com
GMAIL_APP_PASSWORD=your_16_character_app_password
```

**例:**
```env
GMAIL_USER=yamashita-j@consuldent.jp
GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
```
（実際にはスペースを削除して `abcdefghijklmnop` のように設定）

### ステップ3: 設定の確認

```bash
cd server
npm run check-env
```

以下のように表示されれば成功です：
```
✓ GMAIL_USER: 設定済み
✓ GMAIL_APP_PASSWORD: 設定済み（16文字）
```

### ステップ4: サーバーの再起動

```bash
cd server
npm run dev
```

サーバー起動時に以下のように表示されれば成功です：
```
✓ Gmail認証情報が設定されています。
```

## トラブルシューティング

### アプリパスワードが表示されない場合

- 2段階認証が有効になっているか確認
- Google Workspaceアカウントの場合は、管理者がアプリパスワードを許可しているか確認

### メール送信が失敗する場合

1. アプリパスワードが正しいか確認（16文字、スペースなし）
2. Gmailアカウントが正しいか確認
3. サーバーログを確認してエラーメッセージを確認
